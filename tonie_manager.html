Two-step process for merging MP3 files and converting to Tonie format

1
Merge MP3 Files with Python
Merge multiple MP3 files into a single file and optionally embed cover artwork using the Python script.

Prerequisites:

Install required Python packages:
pip install pydub mutagen
Note: You'll also need ffmpeg installed on your system for pydub to work.
Basic merge command:
python merge_mp3.py file1.mp3 file2.mp3 file3.mp3 -o output.mp3
Merge with cover art:
python merge_mp3.py *.mp3 -o merged.mp3 -c cover.jpg
Merge all MP3s in a directory:
python merge_mp3.py /path/to/files/*.mp3 -o result.mp3 -c artwork.png

Notes:

  • Input files should be MP3 format
  • Cover art can be JPEG or PNG format
  • The script will automatically add .mp3 extension if missing from output filename
  • Files are merged in the order specified
2
Convert to Tonie Format with Docker
Convert the merged MP3 file to Tonie-compatible format using the tonie-podcast-sync Docker container.

Prerequisites:

Docker must be installed and running on your system.
Pull the Docker image:
docker pull ghcr.io/soenkebruns/tonie-podcast-sync:main
Convert merged MP3 to Tonie format:
docker run --rm -v $(pwd):/data ghcr.io/soenkebruns/tonie-podcast-sync:main ffmpeg -i /data/merged.mp3 -ar 48000 -ac 2 -b:a 128k /data/tonie_output.mp3
For Windows (PowerShell):
docker run --rm -v ${PWD}:/data ghcr.io/soenkebruns/tonie-podcast-sync:main ffmpeg -i /data/merged.mp3 -ar 48000 -ac 2 -b:a 128k /data/tonie_output.mp3
For Windows (CMD):
docker run --rm -v %cd%:/data ghcr.io/soenkebruns/tonie-podcast-sync:main ffmpeg -i /data/merged.mp3 -ar 48000 -ac 2 -b:a 128k /data/tonie_output.mp3

Notes:

  • The Docker command mounts your current directory as /data in the container
  • Input and output files should be in the current directory
  • Tonie format specifications: 48kHz sample rate, 2 channels (stereo), 128k bitrate
  • Replace merged.mp3 with your actual merged file name
  • Replace tonie_output.mp3 with your desired output name

Complete Workflow Script
Here's a complete script that combines both steps for easy execution.
Bash script (Linux/Mac):
#!/bin/bash # Tonie Workflow - Complete Script # Step 1: Merge MP3 files echo "Step 1: Merging MP3 files..." python merge_mp3.py *.mp3 -o merged.mp3 -c cover.jpg # Step 2: Convert to Tonie format echo "Step 2: Converting to Tonie format..." docker run --rm -v $(pwd):/data ghcr.io/soenkebruns/tonie-podcast-sync:main ffmpeg -i /data/merged.mp3 -ar 48000 -ac 2 -b:a 128k /data/tonie_output.mp3 echo "✓ Complete! Your Tonie file is ready: tonie_output.mp3"
PowerShell script (Windows):
# Tonie Workflow - Complete Script # Step 1: Merge MP3 files Write-Host "Step 1: Merging MP3 files..." python merge_mp3.py *.mp3 -o merged.mp3 -c cover.jpg # Step 2: Convert to Tonie format Write-Host "Step 2: Converting to Tonie format..." docker run --rm -v ${PWD}:/data ghcr.io/soenkebruns/tonie-podcast-sync:main ffmpeg -i /data/merged.mp3 -ar 48000 -ac 2 -b:a 128k /data/tonie_output.mp3 Write-Host "✓ Complete! Your Tonie file is ready: tonie_output.mp3"

Usage:

  • Save the script as tonie_workflow.sh (Bash) or tonie_workflow.ps1 (PowerShell)
  • Make it executable (Bash): chmod +x tonie_workflow.sh
  • Run it in a directory containing your MP3 files and cover image
  • The final Tonie-ready file will be tonie_output.mp3
